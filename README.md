# PocketSmart-AI - AI Financial Advisor

An intelligent AI-powered personal finance assistant that provides smart financial advice, budget planning, and investment guidance.

## Features
- Personal Finance Management
- Budget Analysis
- AI-Powered Financial Advice
- Investment Guidance
- Expense Tracking

## Tech Stack
- Python
- Flask
- Google Generative AI

## How to Run
1. Clone the repository
2. Install dependencies: pip install -r requirements.txt
3. Run: python app.py
